# Tech Context

## Technology Stack
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB
- **Cache**: Redis
- **Language**: JavaScript

## Dependencies
- **Core**: `express`, `mongoose`, `redis`, `dotenv`
- **Auth**: `jsonwebtoken`, `bcryptjs`, `firebase-admin`
- **Utils**: `lodash` (implied or similar), `date-fns`/`moment` (if any), `zod` (validation)
- **External Services**: Cloudinary (media), Paystack (payments), Brevo/SIB (email)

## Development Setup
- `npm run dev`: Starts the server with `nodemon`.
- `npm run dev:mock-redis`: Starts with mock Redis.
